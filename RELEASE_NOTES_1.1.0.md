# MGD JTL SEO & PageSpeed v1.1.0

Erste öffentliche Release-Version des eigenständigen Plugins.

Schwerpunkte dieser Version sind eine konservative LCP-Optimierung für JTL-/OPC-Startseiten, kleine renderblockierende CSS-Dateien, Bild-Decoding, optionale Resource-Hints sowie ein verständlicher Administrationsbereich.

Neu ist außerdem die sichere GitHub-Release-Prüfung. Das Plugin prüft höchstens alle zwölf Stunden auf eine neuere stabile Version und bietet bei Bedarf den offiziellen Release-Download an. Automatisches Überschreiben von Plugin-Dateien findet in dieser Version bewusst nicht statt.

Die interne Plugin-ID `MGD_SEOoverride_Plugin` wurde beibehalten, damit produktive Installationen der Testversion 1.0.0 aktualisiert werden können.

Vor dem Einsatz auf produktiven Shops wird ein Backup empfohlen. Nach der Installation Cache leeren, Shopfunktionen prüfen und PageSpeed in mehreren Läufen vergleichen.
