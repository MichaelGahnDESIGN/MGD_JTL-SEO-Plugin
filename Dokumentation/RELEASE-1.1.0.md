# Release 1.1.0

Version 1.1.0 ist die erste öffentliche Version des eigenständigen Projekts.

Sie basiert auf einer zuvor produktiv getesteten 1.0.0 und erweitert diese um einen eigenen Administrationsbereich, öffentliche Dokumentation, GitHub-Updateprüfung, Release-Automation und klarere Sicherheitsgrenzen.

Vor einem produktiven Rollout sollten Startseite, Kategorie, Produkt, Warenkorb und Checkout geprüft werden. Anschließend PageSpeed mehrmals auf Mobile und Desktop messen.
