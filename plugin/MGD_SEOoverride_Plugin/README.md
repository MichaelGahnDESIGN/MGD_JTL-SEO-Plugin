# MGD JTL SEO & PageSpeed – Pluginpaket

Dieser Ordner ist das installierbare JTL-Shop-5-Plugin. Für ein Release muss genau der Ordner `MGD_SEOoverride_Plugin` als oberster Ordner in der ZIP enthalten sein.

Die interne Plugin-ID wird aus Kompatibilitätsgründen mit der produktiven Testversion beibehalten. Der sichtbare Produktname ist „MGD JTL SEO & PageSpeed“.

Siehe die ausführliche Projektdokumentation im Repository-Root und im Ordner `wiki/`.
